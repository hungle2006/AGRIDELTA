# AGRIDELTA — Roots Edition

A Vietnamese eco-agriculture web app with a seed-to-harvest opening, scroll-driven root-system user guide, and responsive field-management prototype.

- Website: https://agridelta.vercel.app
- Live source project: `hungle2006/AGRIDELTA`
- Frontend: Vite, vanilla JavaScript, CSS
- Root-guide onboarding: `root-guide.js` and `root-guide.css`
- 3D model: `public/assets/agridelta_seed_to_harvest_model.glb`
- Blender source script: `blender/seed_to_harvest.py`

## Getting started

```bash
npm install
npm run dev
```

## Important

**Prototype/demo only.** Account sign-in and demo data are stored client-side; they are not secure authentication or shared production data. Do not enter real passwords or sensitive farm records. Add a proper server-side authentication backend before inviting real users. The 3D model is static; the Blender growth animation requires Blender rendering and web integration.

The root-guide interaction reveals steps as you scroll and links to the relevant features. The source repository is being initialized from the already published AGRIDELTA Roots Edition release.
